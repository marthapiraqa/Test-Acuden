# Grabaciones de Codegen

Ejecutar ` .\pw.cmd run codegen ` desde la raíz. Se abre Chromium y el Inspector.
Realizar un escenario, agregar aserciones desde el Inspector y cerrar las ventanas.
Cada ejecución guarda un archivo nuevo en esta carpeta.

Las grabaciones están excluidas de Git porque pueden contener contraseñas y datos personales.
No importar grabaciones directamente a la suite: revisar y transformar usando `docs/CODEGEN-POM.md`.
